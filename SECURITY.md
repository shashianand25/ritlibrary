# Security Policy

## Supported Versions

| Version | Supported          |
| :------ | :----------------- |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within RIT Library, please do not open a public issue. Instead, report it directly to the project maintainers via email at:

**admin@ritlibrary.org** (or contact the maintainer directly).

Please include:

1. Detailed description of the vulnerability.
2. Steps to reproduce the issue.
3. Potential impact and proposed remediation (if available).

We will acknowledge receipt of your report within 48 hours and work diligently to release a patch promptly.
